# Design direction (DRAFT - refine before building UI)

Modern, dimensional, warm. Confident and calm, not "hacker terminal".

## Tokens (draft)

- Color: background #F6F3EE / #0E0E10 (follow system), text #141414 / #F3EFE8, one accent #E8250D used sparingly.
- Type: characterful serif for headings, grotesk for body, mono ONLY for dates and stack tags.
- Radius 16-20px. Large type, generous whitespace.

## Hard bans

- Bracketed labels like "[ 01 / WORK ]", pseudo-technical captions, fake status chips.
- 2x2 equal-card grids, glassmorphism, gradient washes, emoji icons, logo marquees.
- Fake metrics, stale availability dates, invented content.

## Layout

- Work = full-width alternating rows with a real screenshot slot.
- One large 3D moment in the hero only. Static fallback required.
